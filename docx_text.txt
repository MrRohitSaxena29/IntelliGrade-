IntelliGrade – Project Structure Document
AI Answer Sheet Evaluation SystemSoftware Architecture & Folder Structure
1. Project Overview
IntelliGrade is an AI-powered platform that evaluates scanned answer sheets using OCR, rubric-based AI marking, and analytics. The system extracts handwritten text from PDFs, compares answers with a marking scheme, awards marks, and generates detailed feedback.
2. System Architecture
Main components of the application:
Frontend (React + TypeScript)
Backend API (Spring Boot + JWT)
OCR Service (PaddleOCR)
AI Evaluation Service (LLM + Prompt Engineering)
PostgreSQL Database
PDF & Report Generator
Docker Deployment
